## 它到底能做什么

从照顾电脑开始：清理、加速、控温、体检、跑分、看护别的电脑。每一项都基于这台电脑的真实测量，而不是猜测。

### 清理与加速
扫描应用缓存、废纸篓、旧安装包、大文件、虚拟机、本地 AI 模型和微信等应用数据，生成带大小的**清理清单**；安全的项目已经勾好，点一次清完。缓存直接删除（应用用到时会自动重建），其他项目移入废纸篓，随时找回。**不是重装系统，也不是恢复出厂设置。**

### 控温与硬件健康
监测处理器和硬盘温度，和这台电脑平时的水平比较；找出此刻**是哪些程序让电脑发热**；长期跟踪硬盘健康（SMART），在故障出现前发现损耗。

### 性能与本地 AI
测出硬盘真实读写速度和处理器性能；压力测试最长可做 4 小时烤机，同时观察温度和稳定性；内存够的话，可以部署本地 AI 大模型（Ollama），让闲置的算力干活。

### 空间与资源分析
告诉你磁盘空间都去了哪里、最大的文件夹、有哪些软件可以更新，以及处理器和内存有多少是闲着的。

### 远程与其他电脑
用一次性邀请码配对多台电脑，查看另一台的状态、远程体检、委托它做事；用你已有的 SSH 密钥巡检服务器；把任务交给其他 AI 智能体（Claude Code、Codex 等）再把结果带回来。

### 安全体检
逐个检查正在运行的程序有没有可疑迹象（从临时或下载目录启动、文件已删除却还在运行、对外开放端口、长时间占满处理器的陌生程序、以管理员身份运行在谁都能改的目录里），再检查防火墙、磁盘加密、安全更新和备份。**只检查不动手**，发现可疑的会告诉你是什么、在哪里、该怎么处理。

## 给 AI 智能体

RelVectors 是第一个为机器本身打造的 agent：别的 agent 替人做事，RelVectors 替电脑说话。其他 agent 把电脑本身的事交给它，就能得到真实测量、安全的手（授权闸门、可撤销、主人审批卡片）、跨会话的记录，以及到其他电脑上办事的能力。

- **MCP：** `claude mcp add relvectors -- rv mcp --agent claude-code`（其他客户端：`rv mcp --agent <名字>`，stdio）
- **A2A：** 名片在 `http://127.0.0.1:47100/.well-known/agent-card.json`，对话接口是 `/a2a` 的 JSON-RPC `message/send`
- **命令行：** `rv --json status`、`rv --json findings`、`rv --json tasks`

## 常见问题

**会删掉我的文件吗？** 只清理你在清单里勾选的项目。缓存直接删除（应用会自动重建），其他的移入废纸篓，随时能找回来。

**会上传我的数据吗？** 不会。它在你的电脑上读取电脑的状态。你的文档只会在你交办的任务里读，没有你的允许不会发给云端 AI。

**需要联网或订阅 AI 吗？** 安装不需要联网。AI 能力既可以用本地模型（Ollama、oMLX、LM Studio），也可以配置云端模型；用本地模型时数据留在本机。

**会拖慢电脑吗？** 不会。它以低优先级运行，几乎不占处理器和内存。

**「清理」是恢复出厂设置吗？** 不是。它只做清理和加速，不重装任何东西，也不重置任何设置。
